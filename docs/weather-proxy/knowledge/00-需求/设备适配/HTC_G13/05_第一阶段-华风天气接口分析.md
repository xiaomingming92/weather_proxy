# 第一阶段：华风天气接口分析

## 概述

本文档记录 HTC G13 (Wildfire S) 国行版华风天气接口的逆向分析结果。

## 分析目标

- 华风天气 API 端点识别
- 请求参数分析
- 响应 XML 格式解析
- 天气代码映射表提取

## 华风天气接口

### 1. API 端点

```
http://htc-mobile.mywtv.cn/getweatheru.asmx/getData?dataType=htc&code=ED926B&sname={城市代码}
```

**参数说明**:
| 参数 | 值 | 说明 |
|------|-----|------|
| `dataType` | `htc` | 数据类型 |
| `code` | `ED926B` | 认证码 |
| `sname` | `{城市代码}` | 城市代码，如 `01011712` |

### 2. 响应 XML 格式

```xml
<?xml version="1.0" encoding="utf-8"?>
<root>
  <CityMeteor CityName="南京">
    <StationInfo StationID="..." Longitude="..." Latitude="..."/>
    <CF ReportTime="...">
      <Period TimeStart="..." TimeEnd="..." 
              Weather="1"          <!-- 天气状况代码 -->
              Tmax="28"            <!-- 最高温度 -->
              Tmin="15"            <!-- 最低温度 -->
              Week="1"             <!-- 星期 -->
              WindDir="东南风"
              WindPower="3"/>
    </CF>
    <SK>
      <Info Weather="1"           <!-- 当前天气 -->
            Temperature="25"      <!-- 当前温度 -->
            WindDir="东南风"
            WindPower="3"
            WindSpeed="12"
            Humidity="45"/>
    </SK>
  </CityMeteor>
</root>
```

### 3. 关键字段映射

| XML 字段 | 说明 | 示例值 |
|----------|------|--------|
| `CityMeteor.CityName` | 城市名称 | "南京" |
| `CF.Period.Weather` | 天气状况代码 | "1" |
| `CF.Period.Tmax` | 最高温度 | "28" |
| `CF.Period.Tmin` | 最低温度 | "15" |
| `CF.Period.Week` | 星期 | "1" (周一) |
| `SK.Info.Weather` | 当前天气代码 | "1" |
| `SK.Info.Temperature` | 当前温度 | "25" |
| `SK.Info.Humidity` | 湿度 | "45" |
| `SK.Info.WindDir` | 风向 | "东南风" |
| `SK.Info.WindPower` | 风力 | "3" |

## 分析结论

1. **华风接口独立**: 国行 HTC G13 使用华风天气而非 AccuWeather
2. **XML 格式不同**: 华风使用自定义 XML，与 AccuWeather 格式不兼容
3. **代码映射完整**: 35 个华风天气代码映射到 AccuWeather 代码
4. **需要独立适配**: 华风接口需要单独实现代理服务
