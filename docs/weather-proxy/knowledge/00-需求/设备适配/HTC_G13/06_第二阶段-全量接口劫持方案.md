# 第二阶段：全量接口劫持方案

## 概述

本文档定义 HTC G13 天气服务所有需要劫持的接口，确保代理服务全覆盖，避免 App FC。

## 接口分类

### 1. 华风天气接口（中国版）

| 优先级 | 接口 | URL | 用途 | 状态 |
|--------|------|-----|------|------|
| P0 | 华风天气数据 | `http://htc-mobile.mywtv.cn/getweatheru.asmx/getData?dataType=htc&code=ED926B&sname={城市代码}` | 获取中国城市的天气数据 | ✅ 已分析 |
| P1 | 华风天气（按城市名） | `http://htc-mobile.mywtv.cn/getweatheru.asmx/getData?dataType=htc&code=ED926B&city={城市名}` | 备用接口 | ⚠️ 待实现 |
| P2 | 华风天气详情页 | `http://3g.mywtv.cn/index.jsp?id={城市代码}` | 天气详情跳转 | ⚠️ 待实现 |

### 2. AccuWeather 接口（国际版）

| 优先级 | 接口 | URL | 用途 | 状态 |
|--------|------|-----|------|------|
| P0 | 城市搜索 | `http://htc2.accu-weather.com/widget/htc2/city-find.asp?q={城市名}` | 搜索城市 | ✅ 已实现 |
| P0 | 天气数据（按经纬度） | `http://htc2.accu-weather.com/widget/htc2/weather-data.asp?lat={纬度}&lon={经度}` | 通过坐标获取天气 | ✅ 已实现 |
| P0 | 天气预报（按城市） | `http://htc.accuweather.com/widget/htc/forecast-data_v3.asp?ac=TR2cra9U&loccode={城市代码}` | 获取城市天气预报 | ✅ 已实现 |
| P0 | 经纬度搜索 | `http://htc.accuweather.com/widget/htc/lat-lon-search.asp?ac=TR2cra9U&lat={纬度}&lon={经度}` | 通过坐标查找城市 | ✅ 已实现 |
| P2 | 收藏书签 | `http://www.accuweather.com/?p=htcfav` | 收藏页面 | ⚠️ 可选 |
| P2 | 更多详情 | `http://www.accuweather.com/m/details1.aspx?cityId={城市ID}` | 详情页面 | ⚠️ 可选 |

### 3. WCR（Weather Configuration Resource）接口

| 优先级 | 接口 | URL | 用途 | 状态 |
|--------|------|-----|------|------|
| P1 | WCR 配置（测试） | `http://wcr.htcsense.com/wcr/weather?mid={设备ID}&sku={SKU}&cid={CID}&vs={版本}` | 获取天气服务配置 | ⚠️ 待分析 |
| P1 | WCR 配置（生产） | `http://ec2-122-248-192-161.ap-southeast-1.compute.amazonaws.com:8080/wcr/weather?mid={设备ID}&sku={SKU}&cid={CID}&vs={版本}` | 获取天气服务配置 | ⚠️ 待分析 |

## 风险分析

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 华风接口未实现 | FC | 优先实现 P0 接口 |
| WCR 配置失败 | 可能回退到默认 URL | 实现 WCR 接口或阻止请求 |
| 详情页无法打开 | 功能缺失 | 返回空页面或跳转 |
