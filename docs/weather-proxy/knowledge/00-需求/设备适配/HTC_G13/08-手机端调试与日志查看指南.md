# 手机端调试与日志查看指南

## 1. 后端接口端口配置

### 1.1 服务端口

| 服务 | 端口 | 说明 |
|------|------|------|
| weather_proxy | 1888 | 主代理服务端口 |

**配置文件：** `weather_proxy/.env`
```
PORT=1888
HOST=0.0.0.0  # 生产环境
```

### 1.2 接口路由

| 接口路径 | 用途 | 响应格式 |
|---------|------|---------|
| `/api/v1/htc-g13/weather` | 新天气 App JSON 接口 | JSON |
| `/getweatheru.asmx/getData` | 华风天气 XML 接口（国行） | XML |
| `/widget/htc/forecast-data_v3.asp` | AccuWeather XML 接口（国际版） | XML |
| `/widget/htc2/city-find.asp` | 城市搜索 | XML |
| `/widget/htc/lat-lon-search.asp` | GPS 定位 | XML |

## 2. 手机端日志查看方法

### 2.1 使用 ADB Logcat 查看日志

```bash
# 连接手机后查看日志
adb logcat -s Weather:D WeatherActivity:D WeatherApi:D

# 过滤特定标签
adb logcat | grep -E "(Weather|HTC|QWeather)"
```

### 2.2 关键日志标签

| 标签 | 说明 | 查看内容 |
|------|------|---------|
| `Weather` | 天气应用主标签 | 请求 URL、响应状态 |
| `WeatherApi` | API 调用标签 | 请求参数、响应数据 |
| `CitySearchHelper` | 城市搜索标签 | 搜索关键词、返回结果 |
| `WeatherCodeUtil` | 天气代码标签 | 代码映射、转换结果 |
| `WeatherProvider` | 数据提供器标签 | 数据库操作 |

### 2.3 日志关键字符

**请求相关：**
- `Request URL:` - 请求地址
- `Request params:` - 请求参数
- `HTTP GET/POST` - HTTP 方法

**响应相关：**
- `Response code:` - 响应码（200、404、500等）
- `Response body:` - 响应体内容
- `JSON:` - JSON 格式数据
- `XML:` - XML 格式数据

**错误相关：**
- `Error:` - 错误信息
- `Exception:` - 异常堆栈
- `Failed to` - 操作失败

## 3. 根据端口查找响应数据

### 3.1 华风天气接口（国行版）

**端口：** 1888
**请求特征：**
```
GET /getweatheru.asmx/getData?dataType=htc&code=ED926B&sname=01011712
```

**日志查找关键词：**
- `getweatheru.asmx` - 端点标识
- `dataType=htc` - 数据类型
- `sname=` - 城市代码参数
- `CityMeteor` - XML 根元素
- `CF` - 预报数据节点
- `SK` - 实况数据节点

**响应数据关键字符：**
```xml
<CityMeteor CityName="南京">
  <CF ReportTime="...">
    <Period Weather="1" .../>  <!-- Weather 属性是天气代码 -->
  </CF>
  <SK>
    <Info Weather="1" .../>    <!-- Weather 属性是当前天气代码 -->
  </SK>
</CityMeteor>
```

### 3.2 新天气 App JSON 接口

**端口：** 1888
**请求特征：**
```
GET /api/v1/htc-g13/weather?city=扬州
```

**日志查找关键词：**
- `/api/v1/htc-g13` - API 路径
- `city=` - 城市参数
- `"code":"200"` - 成功响应
- `"icon":"` - 天气图标代码
- `"text":"` - 天气描述文本

**响应数据关键字符（JSON）：**
```json
{
  "code": "200",
  "city": {"name": "扬州", ...},
  "now": {
    "temp": "25",
    "icon": "100",      // 天气图标代码
    "text": "晴"        // 天气描述
  }
}
```

### 3.3 AccuWeather 接口（国际版）

**端口：** 1888
**请求特征：**
```
GET /widget/htc/forecast-data_v3.asp?ac=TR2cra9U&loccode=ASI|CN|JS|Yangzhou
```

**日志查找关键词：**
- `forecast-data_v3.asp` - 端点标识
- `ac=TR2cra9U` - 认证参数
- `loccode=` - 位置代码
- `<weather>` - XML 根元素
- `<cc>` - 当前天气节点
- `<dayf>` - 预报数据节点

**响应数据关键字符：**
```xml
<weather>
  <loc>Yangzhou</loc>
  <cc>
    <tmp>25</tmp>
    <icon>1</icon>      <!-- 天气图标代码 -->
    <cond>Sunny</cond>  <!-- 天气描述 -->
  </cc>
  <dayf>...</dayf>
</weather>
```

## 5. 网络抓包方法

### 5.1 使用 Charles/Fiddler 抓包

1. **设置代理：** 手机和电脑在同一 WiFi，设置手机代理为电脑 IP:8888
2. **安装证书：** 手机安装 Charles/Fiddler 证书
3. **过滤域名：** 设置过滤器，只查看代理服务器 IP:80 的请求

### 5.2 使用 tcpdump（需要 Root）

```bash
# 在手机上运行（需要 root）
su
tcpdump -i any -A -s 0 port 80

# 保存到文件
adb shell tcpdump -i any -w /sdcard/capture.pcap port 80
adb pull /sdcard/capture.pcap
```

## 6. 日志分析技巧

### 6.1 快速定位问题

1. **先查请求：** 确认请求 URL 和参数正确
2. **再查响应：** 查看响应码和数据内容
3. **对比映射：** 检查天气代码映射是否正确
4. **查看转换：** 确认数据转换过程无误

### 6.2 常见问题日志特征

| 问题 | 日志特征 | 解决方法 |
|------|---------|---------|
| 网络错误 | `ConnectException`、`Timeout` | 检查网络连接、服务器状态 |
| 404 错误 | `Response code: 404` | 检查接口路径、城市代码 |
| 500 错误 | `Response code: 500` | 检查服务器日志、参数格式 |
| 数据解析错误 | `JSONException`、`XmlPullParserException` | 检查响应格式、编码 |
| 天气代码错误 | `icon: "801"`、`Weather="20"` | 检查映射表、数据源 |

## 7. 调试工具推荐

### 7.1 Android Studio

- **Logcat 窗口：** 实时查看日志
- **Network Inspector：** 查看网络请求和响应
- **Profiler：** 监控网络流量

### 7.2 命令行工具

```bash
# 实时查看日志
adb logcat -c && adb logcat

# 保存日志到文件
adb logcat -d > log.txt

# 过滤特定进程
adb logcat --pid=$(adb shell pidof -s com.htc.Weather)
```

## 8. 注意事项

1. **日志级别：** 发布版本可能关闭 DEBUG 日志，需要开启或查看 INFO 级别
2. **日志缓冲：** 日志缓冲区有限，及时保存重要日志
3. **敏感信息：** 日志中可能包含 API Key 等敏感信息，注意保护
4. **性能影响：** 大量日志输出可能影响性能，生产环境谨慎使用
