# 第一阶段：基础服务搭建

## 目标

构建基于Node.js 24的天气API代理服务，支持HTTP协议，为对接WeatherWidget和WeatherTV做准备。

## 技术栈

- Node.js 24
- TypeScript
- ES Module
- Express.js
- 和风天气API

## 核心实现

### 1. 基础配置

**package.json**:
```json
{
  "name": "weather-proxy",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "dev": "NODE_ENV=development tsx watch src/server.ts",
    "build": "tsc",
    "start": "NODE_ENV=production node dist/server.js"
  }
}
```

**环境变量**:
```env
NODE_ENV=development
PORT=1888
HOST=localhost
QWEATHER_API_KEY=your_api_key_here
QWEATHER_PUBLIC_KEY=your_public_key_here
CACHE_TTL=3600
```

### 2. 核心服务

**主服务** (`src/server.ts`):
```typescript
import express from 'express';
import { config } from './config';
import weatherRouter from './routes/weather';

const app = express();
app.use(express.json());
app.use('/api/weather', weatherRouter);
app.listen(config.port, () => {
  console.log(`Weather proxy running on port ${config.port}`);
});
```

**天气API服务** (`src/services/weather-api.ts`):
- `getWeather(cityName)` - 获取城市天气（城市ID、当前天气、7天预报）
- `getCityId(cityName)` - 获取城市ID
- `getNowWeather(cityId)` - 获取当前天气
- `getForecast(cityId)` - 获取7天预报

**数据转换服务** (`src/services/data-transform.ts`):
- `toWidgetXml()` - 转换为Widget XML格式
- `generateCurrentWeatherXml()` - 生成当前天气XML
- `generateForecastXml()` - 生成预报XML

**缓存服务** (`src/services/cache.ts`):
- 基于NodeCache实现内存缓存
- 默认TTL: 3600秒

## API端点

### 基础URL
```
http://localhost:1888/api/weather
```

### 请求参数

| 参数名 | 类型 | 必需 | 说明 |
|-------|------|------|------|
| sname | string | 是 | 城市名称，例如：北京 |
| dataType | string | 是 | 数据类型：ztev3widgetskall/ztewidgetsk/ztewidgetcf |
| code | string | 否 | 预留参数 |

### 响应结构

**当前天气响应** (`ztev3widgetskall`/`ztewidgetsk`):
```xml
<?xml version="1.0" encoding="utf-8"?>
<weather>
  <city>北京</city>
  <temp>1</temp>
  <weather>5</weather>
  <reporttime>2026-02-05T09:43:40.829Z</reporttime>
</weather>
```

**天气预报响应** (`ztewidgetcf`):
```xml
<?xml version="1.0" encoding="utf-8"?>
<weather>
  <city>北京</city>
  <reporttime>2026-02-05T17:42+08:00</reporttime>
  <startTime1>2026-02-05 00:00:00</startTime1>
  <endTime1>2026-02-05 23:59:59</endTime1>
  <week1>周四</week1>
  <condition1>5</condition1>
  <tempMin1>-2</tempMin1>
  <tempMax1>2</tempMax1>
  <startTime2>...</startTime2>
  ...
</weather>
```
